The social inbox in Franchise Systems Ai (FS Ai) brings Instagram and Facebook direct messages and comments into one queue.

> You need Socials enabled for a Full OS brand and a connected Instagram or Facebook account. Reading requires Marketing access; sending replies and managing saved replies require write access.

### Find a conversation

1. Go to **Marketing** → **Socials** and select **Inbox**.
2. Use **Search inbox** to find a person or message. The type, platform, and account filters narrow the queue.
3. Open a conversation to read the thread and see which of your accounts received it.

The queue controls include **Unread**, **Needs reply**, and **Mine**. If no eligible account is connected, the inbox prompts you to connect one.

![Conversation queue and selected direct-message thread](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/socials-inbox/socials-inbox-thread.png)

### Write a response

Type your response in **Reply**. Check the line above the composer: it identifies the account you are replying as and whether the response is a direct message or a public comment.

The composer shows reply-window restrictions. If a conversation's reply window has expired, the response can be blocked until the person messages again.

For comments, **Reply privately** is available only when the platform permits it. Review the delivery mode before sending; the send action responds to the customer.

![Comment thread with public and private response controls](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/socials-inbox/socials-inbox-comment.png)

### Use saved replies

1. Open **Saved replies** and select a saved response. It replaces the text currently in the composer.
2. Review and personalize the response before sending it.
3. To save reusable wording, write it in the composer, open **Saved replies**, and choose **Save current text as reply**.
4. Enter a name and click **Save**.

![Saved replies menu and reusable response](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/socials-inbox/socials-inbox-saved.png)

The name identifies the saved reply in the menu.

![Naming a new saved reply](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/socials-inbox/socials-inbox-save-form.png)

Saving reusable wording does not send it to the customer. Sending the response is a separate action.
