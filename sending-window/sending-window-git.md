Set the default hours for workflow and campaign emails in Franchise Systems Ai (FS Ai). The sending window uses the timezone you choose for the brand.

> You need permission to edit brand settings to change this window.

### Find the Sending Window

Open **Connections** under Brand in your settings, then find **Sending window**. On FranDev (Recruitment Funnel), this card is on the **Profile** page under Brand instead.

You reach **Settings** from your profile picture at the bottom of the sidebar.

### Set Your Hours

1. Choose the **Timezone** for your sending schedule.
2. Set **From** to the first hour emails can send.
3. Set **Until** to the end of the sending window.
4. Turn on **Exclude weekends** to exclude Saturday and Sunday from this window.

![Sending window timezone, hours, and weekend setting](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/sending-window/sending-window-settings.png)

Valid changes save as you make them. There is no separate save step.

The end must be later than the start. If you move the start past the current end, the card shows “End must be after start.” Choose a later end time to make the window valid.

![Sending window with an invalid start and end pair](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/sending-window/sending-window-error.png)

An invalid combination does not replace the saved window.

### Brand Defaults and Individual Sends

The brand window is the default for workflow emails. A valid window chosen for an audience enrollment overrides that default for that enrollment.

Newsletter scheduling also lets you choose sending hours and a timezone for that send. Changing those choices does not edit the brand's settings.

If an email is waiting outside its sending hours, check the window chosen for that send as well as the brand default.

See *[How to Send Email]* for newsletter scheduling and campaign enrollment.
