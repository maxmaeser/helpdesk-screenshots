Creative Editor lets you build images, PDFs, and slide decks in Franchise Systems Ai (FS Ai). Your saved designs stay in the Library so you can open them again.

This walkthrough covers the operator workspace in Full OS. Choose the brand you want to work with before starting.

### Start a design

1. Open **Studio**, then **Creative Editor** in the sidebar.
2. Click **New Design** to open a blank canvas.

![Creative Editor designs page](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/creative-editor/creative-editor-designs.png)

3. Enter a **Design name** in the editor header.
4. In the left **Add** panel, choose a text preset such as **Title** to place text on the canvas.

![Creative Editor with a text element added](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/creative-editor/creative-editor-canvas.png)

The Add panel also contains shapes, stickers, and Library images. **Layers** lists the elements in your design, while **Properties** shows controls for the selected element or page.

### Save your work

5. Click **Save** in the header.
6. In the dialog, check the **Name**, choose a **File type**, and click **Save**.

![Save dialog with the design name and file types](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/creative-editor/creative-editor-save.png)

PNG and JPEG hold a single page. For multiple pages, use PDF or Slides. Saving preserves the editable design alongside its file.

### Import or export a file

**Import** opens an image, PDF, or PowerPoint file as a new design. Save your current work first if you want to keep it.

To download a finished file, click **Export**. Choose the file type and pages, choose **Download** as the destination, then click the download button at the bottom.

![Export dialog with file types, pages, and destination](https://raw.githubusercontent.com/maxmaeser/helpdesk-screenshots/master/creative-editor/creative-editor-export.png)

Export offers PNG, JPEG, PDF, and **PowerPoint**. Review any conversion notes before exporting PowerPoint. An export gives you an output file; use Save to keep your editable work.
